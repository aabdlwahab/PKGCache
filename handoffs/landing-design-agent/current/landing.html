the problem

Your builds keep downloading the same dependencies.

Across CI runners and developer machines, repeat downloads slow builds, consume bandwidth, and become a hard stop when the network is disconnected.

the waiting

Repeat downloads stall builds

Large images and wheels cross the same network again while machines wait for work they have already done.

the sprawl

A cache for every ecosystem

Separate services for containers, Python, Node and system packages multiply configuration, maintenance and failure points.

the wall

One missing package stops the build

Disconnected environments cannot reach upstream registries, so an uncached dependency can stop the entire pipeline.

one cache, every ecosystem

Fetch once. Keep repeat package requests local.

Point your existing package clients at pkgcache. It fills on demand, serves cached content from your infrastructure, and combines concurrent misses into one upstream transfer.

01

Local after the first pull

Once an artifact is cached, repeat requests are served from your infrastructure instead of the public registry.

02

One fetch, shared as it arrives

When several machines request the same uncached artifact together, pkgcache opens one upstream stream and serves them all.

03

One service for the build stack

Containers, Python, Node, system packages, Git and generic artifacts share one cache process and two predictable endpoints.

LOCALcached artifact → served from your infrastructure
ONCEuncached artifact → one upstream stream shared by concurrent callers
VALIDfailed or incomplete downloads are never committed as cached content

versioned cache state

Checkpoint the cache without stopping builds.

Capture the cached content and its ledger while the service keeps running. Every checkpoint becomes an auditable restore point and a source for air-gap transfer.

  1. captureCheckpointRecord exactly what the cache holds while package traffic continues.
  2. transferExport the deltaStage only the cache changes needed on the other side.
  3. recoverRoll backRestore a known checkpoint when a build environment must be reproduced.

built for disconnected networks

Bring the cache with you. Keep cached builds running.

Export a checkpoint delta, move it through your approved transfer process, and import it on the far side. Package clients keep using the cache with upstream access disabled.

  1. moveCarry the deltaCopy the exported cache changes to approved removable media or an internal transfer path.
  2. importLoad it offlineImport the checkpoint on the disconnected host and start the cache in offline mode.
  3. serveBuild cache-onlyCached dependencies resolve normally. An uncached request fails clearly instead of attempting upstream access.

Six ecosystems · one service

One cache service for the tools your builds already use.

Five HTTPS roles share :8443; apt and apk use the :3142 forward proxy. Existing commands stay familiar, and the cache fills on demand as builds run.

containersDocker Hub · GHCR · Quay

Container images

Cache images from Docker Hub, GHCR and Quay. Shared layers are stored once by digest.

$ docker pull \cache:8443/dockerhub/library/python:3.12-slim
pythonpip · uv

Python packages

Download large wheels once, then serve repeat installs from your own infrastructure.

$ pip install \--index-url https://cache:8443/global/pypi/root/pypi/+simple/ \numpy
nodenpm client

Node packages

Keep repeat installs local and make cached packages available in offline mode.

$ npm install \--registry https://cache:8443/global/npm/ \left-pad
systemapt · apk

System packages

Serve cached Debian, Ubuntu and Alpine packages to the fleet through one forward proxy.

$ Acquire::http::Proxy"http://cache:3142";
gitread-only mirrors

Git repositories

Clone and fetch cached branches and tags from a local read-only mirror, online or offline.

$ git clone \https://cache:8443/global/git/github.com/pallets/click.git
everything elsedownloads · uploads

Anything else

Store artifacts that have no package manager, including your own versioned build outputs.

$ wget \https://cache:8443/global/files/builds/v1.2/app.tar.gz
